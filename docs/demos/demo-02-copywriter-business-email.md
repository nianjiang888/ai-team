# 演示2：✍️ 文案助理 — 商务邮件撰写

> **对应能力**：CW-03 商务邮件撰写
> **对应模板**：商务邮件万能生成器
> **节省时间**：15分钟 → 2分钟（7x提效）

---

## 演示场景

小王需要给甲方客户写一封邮件，催一下合同签署进度。这个合同已经拖了两周了，他需要语气委婉但明确地表达紧迫感。以前他会反复斟酌措辞，现在直接让文案助理出稿。

---

## 模拟输入

```
帮我写一封商务邮件。

邮件信息：
- 收件人：甲方客户张总（市场总监）
- 邮件目的：催合同签署进度，合同已经拖了两周了
- 核心内容：我们这边项目组已经就位，随时可以启动，但需要合同先签了。
  另外，之前谈好的5月1日上线目标，如果不尽快启动可能来不及
- 语气要求：委婉但明确，不要太生硬
- 需要对方回复：是的，希望对方确认签约时间

我们公司：智远科技有限公司
甲方公司：星辰集团
项目名：智能客服系统升级项目
```

---

## 使用技巧

1. **用大白话描述就行**：你想说什么就说什么，不用管措辞，AI会帮你润色
2. **明确"需要对方做什么"**：这是邮件最重要的部分，不要漏
3. **语气选择很关键**：催进度用"委婉但明确"、投诉用"正式且坚定"、邀约用"热情亲切"
4. **主题行别偷懒**：好主题行 = [公司名] + [项目名] + [具体事项]，对方一眼看懂优先级
