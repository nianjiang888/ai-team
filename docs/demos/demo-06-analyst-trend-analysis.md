## 使用技巧

1. **至少3个月数据**：太短的趋势没有参考价值
2. **关注异常而非平均值**：异常点才是决策的关键
3. **环比同比都要看**：环比看短期变化，同比看长期趋势
4. **建议比数据更有价值**：老板要的不是数字，是"接下来怎么办"
