# 演示1：✍️ 文案助理 — 周报自动生成

> **对应能力**：CW-01 周报/日报自动生成
> **对应模板**：周报自动生成器
> **节省时间**：30分钟 → 3分钟（10x提效）

---

## 演示场景

周五下午5点半，产品经理小王打开电脑准备写周报。这周他做了用户调研、竞品分析、产品方案评审，还有很多零散的沟通记录散落在微信和钉钉里。以前他至少要花30分钟整理这些碎片信息。

现在，他只需要把工作记录粘贴给文案助理。

---

## 模拟输入

```

1. 周一：和运营团队开了用户调研启动会，确定了调研目标和问卷大纲
2. 周二：跑了3个用户深度访谈（分别在望京、西二旗、朝阳门），每个45分钟，做了访谈笔记
3. 周三：竞品分析，研究了X公司的最新功能更新和Y公司的定价策略变化，整理了一份对比表
4. 周四：产品方案评审会，和研发对齐了V2.0的需求范围，砍了2个非核心需求
5. 周五：和UI设计师确认了3个核心页面的交互方案，有个首页改版方案还没定下来

另外这周有个卡点：第三方数据接口的文档不完整，研发反馈对接可能延期一周。
```

| 字数控制 | 容易写多或写少 | 自动控制在500字内 |

## 使用技巧

1. **输入越碎越好**：微信聊天记录、钉钉待办、便签都能直接粘贴
2. **不要自己先整理**：把原始记录直接丢给AI，让TA帮你归类
3. **风险一定要提**：如果有卡点，写进去，周报不是报喜不报忧
4. **每周固定时间用**：建议周五下午设个提醒，养成习惯
