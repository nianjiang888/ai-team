# 演示7：📋 项目管家 — 任务拆解（WBS）

> **对应能力**：PM-02 任务拆解（WBS）
> **对应模板**：任务拆分生成器
> **节省时间**：2小时 → 15分钟（8x提效）

---

## 演示场景

一个自由职业者想做一个AI效率工具的GitHub开源项目，但不知道怎么把"做一个开源项目"这个大目标拆成每天能执行的小任务。以前他可能会直接开始写代码，写着写着就乱了。

---

## 模拟输入

```
帮我把以下项目拆分成可执行的任务。

项目/需求描述：做一个AI效率工具的开源项目，目标是发布到GitHub和SkillHub。
核心功能：50+个Prompt模板，覆盖职场办公、新媒体、数据分析、项目管理、创业副业5大场景。
技术方案：Python + Flask Web界面 + SkillHub技能包形式。
最终交付：GitHub仓库（含文档、示例、README）+ SkillHub上架的技能包。

项目周期：4周
团队规模：1人（我）+ AI辅助
```

## 对比

| 维度 | 不拆直接干 | AI辅助WBS拆解 |
|------|----------|-------------|
| 执行效率 | 写到哪算哪，容易返工 | 每天有明确目标 |
| 进度可见 | 不知道做到哪了 | 一眼看出完成比例 |
| 风险控制 | 出问题才补 | 提前识别关键路径 |
| 并行度 | 串行思维 | 自动标注可并行的任务 |
| 心理压力 | 巨大（一堆事不知道从哪开始） | 每天只关注当天任务 |

---

## 使用技巧

1. **拆到"一个人1-3天能完成"的粒度**：太粗无法跟踪，太细增加管理成本
2. **标注依赖关系**：哪些必须先做、哪些可以并行，这是关键
3. **识别关键路径**：关键路径上的任务延期 = 整个项目延期
4. **每完成一个勾一个**：看着任务一个个被划掉，很有成就感
