# 演示5：📊 数据分析师 — Excel数据清洗

> **对应能力**：DA-01 Excel数据清洗
> **对应模板**：Excel数据清洗助手
> **节省时间**：1小时 → 5分钟（12x提效）

---

## 演示场景

运营小张从CRM系统导出了一份客户数据表，准备做月度分析。但导出来的数据一塌糊涂：有重复行、有空值、日期格式不统一（有的写2026/4/1，有的写2026-04-01，有的写4月1日），还有些异常值（年龄字段出现了999）。以前她要花1小时慢慢清理。

---

## 模拟输入

```
帮我清洗以下Excel数据。

数据情况描述：
- 数据量：2000行 × 12列
- 存在的问题：

数据样本（前5行）：
```

## AI输出结果

```
═══════════════════════════════════════
       数据清洗方案（6步）
═══════════════════════════════════════

【步骤1】规范列名（必须）
操作：数据 → 删除前后空格
  Excel公式：=TRIM(A1) 或 Ctrl+A → 查找替换（空格替换为空）
  原因：列名有空格会导致后续公式引用出错

【步骤2】去除重复行（必须）
操作：数据 → 删除重复值 → 以"客户ID"列为判断依据
  预计删除：约50行
  验证：删除后行数应为1950左右

【步骤3】统一日期格式（必须）
操作：选中"注册日期"列 → 数据 → 分列 → 日期格式（YMD）
  或用公式：=DATEVALUE(SUBSTITUTE(SUBSTITUTE(A1,"/","-"),"年","-"))
  目标格式：2026-04-01（统一为YYYY-MM-DD）
  验证：排序后检查是否按时间正确排列

【步骤4】处理手机号（必须）
操作：统一为11位纯数字
  Excel公式：=RIGHT(SUBSTITUTE(A1,"-",""),11)
  或：Ctrl+H → 查找"86-" → 替换为空
  验证：检查是否所有手机号都是11位数字

【步骤5】统一城市名称（必须）
操作：建立城市映射表，使用VLOOKUP统一
  "北京 "/"北京市" → "北京"
  "上海市" → "上海"
  Excel公式：=VLOOKUP(TRIM(A1),城市映射表,2,0)
  手动替换也行：Ctrl+H → 逐个替换

【步骤6】处理年龄异常值（必须）
规则：
  - 空值（30行）→ 用中位数填充（=MEDIAN(B:B)），约28岁
  - 负数（-5）→ 标记为异常，填充中位数
  - 999 → 明显是占位符，填充中位数
  Excel公式：=IF(OR(A1<0,A1>120),MEDIAN(B:B),IF(A1="",MEDIAN(B:B),A1))
  验证：检查年龄列是否在合理范围（0-120）

═══════════════════════════════════════
       清洗后验证清单
═══════════════════════════════════════
✅ 总行数 ≈ 1950（去重后）
✅ 无重复客户ID
✅ 日期格式统一为 YYYY-MM-DD
✅ 手机号统一为11位
✅ 城市名称无后缀无空格
✅ 年龄范围 0-120，无空值
✅ 列名无前后空格
```

## 使用技巧

1. **先描述问题，不要先想方法**：告诉AI数据哪里有问题，TA会自动判断用公式还是Power Query
2. **给样本数据**：至少给5行真实数据，AI才能给出准确的公式
3. **分清必须和可选**：有些清洗是必须的（去重、格式统一），有些是可选的（衍生字段）
4. **保留原始数据**：清洗前先复制一份原始表，万一洗坏了还能回溯
