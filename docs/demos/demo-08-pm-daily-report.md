# 演示8：📋 项目管家 — 项目日报生成

> **对应能力**：PM-03 项目日报生成
> **对应模板**：项目日报自动生成
> **节省时间**：30分钟 → 3分钟（10x提效）

---

## 演示场景

项目管家角色——每天下班前要把今天做的事汇总成日报发给团队/领导。以前要花30分钟回忆整理，现在只需要把今天做的事列个关键词清单。

---

## 模拟输入

```
帮我生成今日项目日报。

今日工作记录：
- 完成了文案助理的岗位说明书（role-card.md），包含10个能力模块
- 完成了新媒体运营的岗位说明书，14个能力模块，其中跨平台适配这块花了比较长时间
- 更新了agents/copywriter.py和agents/social_media.py，让它们引用新的岗位说明书
- 下午和设计师聊了看板界面的UI方案，确定了卡片式布局
- 提了个bug：start.py在Windows下路径分隔符有问题

项目背景信息：
- 项目名称：AI效率全能助手 - 产品化项目
- 当前阶段：阶段一（重新包装）
- 总体进度：20%
```

## 对比

| 维度 | 手动写日报 | AI辅助日报 |
|------|-----------|-----------|
| 耗时 | 30分钟 | 3分钟 |
| 完整性 | 容易遗漏小任务 | 自动提取所有事项 |
| 格式统一 | 每天格式不一样 | 自动结构化输出 |
| 风险标注 | 经常忘记 | 自动从描述中识别潜在风险 |
| 明日计划 | 经常空着 | 根据依赖关系自动推导 |

---

## 使用技巧

1. **关键词就行**：不需要写完整句子，"岗位说明书""UI方案""bug"这样的词就够了
2. **有风险一定要说**：领导看日报最关心的就是风险和卡点
3. **每天固定时间**：建议下班前10分钟，养成习惯
4. **进度灯不要撒谎**：🟢正常/🟡有风险/🔴延期，如实标注
