## 使用技巧

1. **卖点要具体**：别写"很好用"，写"周报从30分钟变3分钟"
2. **人设要对**：种草文要像朋友推荐朋友，不是官方广告
3. **emoji别太多**：每段1-2个刚好，太多反而廉价
4. **标签是流量入口**：至少5个，混搭大词和长尾词
