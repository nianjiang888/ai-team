# 演示10：💡 商业顾问 — 竞品分析报告

> **对应能力**：BC-02 竞品深度分析
> **对应模板**：竞品深度分析报告
> **节省时间**：2天 → 2小时（8x提效）

---

## 演示场景

用户想在SkillHub上发布AI效率工具技能包，但不确定市场上已有多少类似产品、定价如何、差异化在哪里。需要一份竞品分析来指导产品定位和定价策略。

---

## 模拟输入

```
帮我做一份竞品分析报告。

我的业务：AI效率全能助手 — 一个包含50+Prompt模板和5个AI员工角色的技能包，
  帮一人公司/小团队用AI自动化日常工作
行业：AI效率工具 / Prompt工程 / 技能包分发
已知竞品：
- "Prompt大师"（另一个SkillHub上的技能包）
- 各种公众号/小红书上卖的"ChatGPT指令大全"PPT

我的产品核心差异：
1. 基于WorkBuddy平台，安装即用
2. 5个AI员工角色（不是散装的模板集合）
3. 有工作流自动化（不是单个Prompt）
4. 持续更新（不是一次性卖PPT）
```

三、每个竞品详细分析
═══════════════════════════════════════

【竞品1：Prompt大师】
• 定位：SkillHub上的Prompt指令集合
• 定价：19.9元（一次性买断）
• 优势：模板数量多（100+），上架早有先发优势
• 劣势：没有角色化设计，模板堆砌感强，没有工作流
• 用户评价：正面"模板多实用"，负面"太多不知道用哪个"

【竞品2：指令大全PPT】
• 定位：ChatGPT指令教程
• 定价：9.9-49.9元（不同版本）

四、差异化策略建议
═══════════════════════════════════════

【市场空白点】
1. 竞品都停留在"模板集合"层面，没有"AI员工+工作流"的概念
2. 竞品更新频率低，用户购买后缺乏持续价值
3. 竞品没有跨场景协作（文案→运营→数据的联动）

【我们的差异化定位】
• 不卖"100个Prompt"，卖"5个AI员工"
• 不卖"一次性模板包"，卖"持续更新的效率系统"
• 不卖"工具"，卖"一人公司AI团队"

【进入策略】
1. 定价29.9元（高于9.9元PPT但低于144元ChatGPT Plus）
2. 上架文案强调"不是模板包，是你的AI团队"
3. 前100名用户免费体验3天，建立口碑
4. 每周更新1个新模板/新场景，制造持续热度

⚠️ 大模型降价后，用户可能直接用AI而非模板

## 使用技巧

1. **竞品分析不是一次性的**：建议每季度更新一次，市场变化快
2. **已知竞品要列**：你知道的竞品告诉AI，TA会帮你补充你没发现的
3. **关注"用户评价"**：竞品的差评就是你的机会
4. **差异化要一句话说清**：如果你不能用一句话说清自己和竞品的区别，用户也说不清
