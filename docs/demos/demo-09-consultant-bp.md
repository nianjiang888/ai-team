## 演示场景

一个想做AI副业的人，想把"AI效率工具技能包"做成一个可持续的产品来卖。他有想法但没有完整的商业计划，需要一份BP来评估可行性，也可能用来找合伙人。以前写BP至少一周，现在2小时出完整稿。

## 使用技巧

1. **输入越具体越好**：项目名、目标用户、核心优势、当前进展，这些信息越详细，BP越精准
2. **财务预测要审视**：AI给出的数字是假设，你需要根据实际情况调整
3. **BP的核心是执行摘要**：让读者3分钟看懂你在做什么，为什么要投你
4. **竞品分析要诚实**：不要假装没有竞品，坦诚分析差异化更有说服力
